Opciones de Exportación Avanzada

Calidad de Compresión 90%
0 (Máxima compresión) 100 (Calidad máxima)
PNG (Portable Network Graphics)
• Peso: Alto
• Características: Sin compresión con pérdida, soporta canal Alfa (transparencia).
• Uso recomendado: Spritesheets, texturas de videojuegos de precisión.
BMP (Bitmap)
• Peso: Muy Alto
• Características: Sin compresión alguna, archivos grandes.
• Uso recomendado: Carga rápida en motores legacy o procesamiento bruto.
TIFF (Tagged Image File Format)
• Peso: Muy Alto
• Características: Excelente fidelidad de color y metadatos.
• Uso recomendado: Edición avanzada e impresión.
JPEG (Joint Photographic Experts Group)
• Peso: Medio
• Características: Compresión con pérdida ajustable, sin transparencia.
• Uso recomendado: Fotografías y fondos sólidos.
ICO (Icon Format)
• Peso: Medio-Bajo
• Características: Optimizado para dimensiones pequeñas.
• Uso recomendado: Favicons e iconos de escritorio.
WebP
• Peso: Bajo
• Características: Alta eficiencia de compresión con y sin pérdida, soporte alpha.
• Uso recomendado: Web moderna y motores webgl.
AVIF (AV1 Image File Format)
• Peso: Mínimo
• Características: Relación compresión/calidad superior basada en AV1.
• Uso recomendado: Optimización extrema de ancho de banda.
GIF (Graphics Interchange Format)
• Peso: Variable
• Características: Soporte para animaciones y transparencia binaria de 1 bit.
• Uso recomendado: Animaciones sencillas o gráficos simples.
